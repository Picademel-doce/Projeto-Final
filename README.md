🍔 Esquina do Sabor

Uma experiência digital desenvolvida para unir praticidade, tecnologia e uma experiência de compra intuitiva.

O Esquina do Sabor é um projeto que busca oferecer uma navegação simples e organizada, com recursos que tornam todo o processo de escolha e realização de pedidos mais prático.

✨ Funcionalidades

- Catálogo de produtos.
- Carrinho de compras.
- Sistema de pedidos.
- Diferentes formas de pagamento.
- Integração entre Frontend e Backend.
- Gerenciamento e armazenamento de dados.
- Histórico de compras.

🎯 Propósito

Aplicar conhecimentos de desenvolvimento web na criação de uma aplicação funcional, organizada e com identidade visual própria.
