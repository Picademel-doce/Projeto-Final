ESQUINA DO SABOR — COMO EXECUTAR

1. Extraia a pasta do projeto.
2. Abra a pasta raiz "esquina_do_sabor_pronto" no VS Code.
3. Abra o terminal nessa pasta.
4. Execute: npm install
5. Depois execute: npm start
6. Acesse: http://localhost:3000

IMPORTANTE:
- Abra o site pelo endereço localhost:3000. Não use Live Server na porta 5500,
  pois o frontend precisa conversar com a API do backend.
- O banco original banco/dados.bd foi preservado e recebeu apenas produtos
  adicionais que ainda não existiam.
- A taxa de entrega é R$ 5,00.
- Pix e cartões são demonstrações acadêmicas; não processam pagamentos reais.
- As imagens de produtos existentes no banco devem ser colocadas em banco/Images
  com os nomes xburguer.jpg, xbacon.jpg, xsalada.jpg, refrigerante.jpg,
  suco.jpg, batata.jpg e onion.jpg para aparecerem nos cards.
